# SpendWise — Personal Expense Tracker

SpendWise is a beginner-friendly Python application that helps users record, manage and track their daily expenses.

## Features

- **Add Expense:** Record an expense with its name, category and amount.
- **View All Expenses:** Display all previously recorded expenses.
- **Total Spending:** Calculate the total amount spent and the number of expenses.
- **Search by Category:** Find expenses belonging to a particular category.
- **Data Persistence:** Save expenses in a JSON file so that data remains available after closing the application.
- **Input Validation:** Handle invalid amounts and empty expense details.

## Technologies Used

- Python
- JSON
- pathlib

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the integrated terminal.
5. Run:

```bash
python spendwise.py
```

6. Follow the menu displayed in the terminal.
